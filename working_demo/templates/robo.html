HONESTY · MARGINAL EDGE OVER BASELINE IS NOISE-LEVEL
Take-all-shorts baseline = +127.0%. ROBO_pnl_weighted = +130.4%. The marginal edge is only +3.4pp across 5 cases (~0.7pp per case) — that's noise at this sample size. The "edge" is dominated by which big-win case got picked, not by signal skill. Real assessment requires a 50+ case backtest, transaction costs, slippage, and borrow fees.

Each line is a reputation regime. The y-axis is mean accuracy across 20 MC seeds at each K. Accuracy stabilizes around K=200–500 — that's the operational target for switching from synthetic-only to real-only deployment. We don't need millions of users; we need ~500 active ones.
▶ ADVERSARIAL ROBUSTNESS · what happens when bad actors arrive
⚠
HONESTY · INDEPENDENT-ACTOR ASSUMPTION DOES A LOT OF WORK
Uniform-vote reputation collapses from 99% → 20% as adversaries grow from 0% → 30% — clear evidence the reputation function matters. P&L-weighted stays robust, BUT: this assumes adversaries vote independently. Coordinated sybil attacks (build fake P&L history, then strike together) would defeat reputation alone and require additional defences (proof-of-stake, KYC, behavioural fingerprinting) that aren't tested here.

▶ KNOWN LIMITATIONS · what this Monte Carlo does NOT prove
  • Class imbalance: 4-of-5 cases are SHORT-correct; accuracy metric is inflated. A balanced 50/50 case mix would give a more honest read.
  • Small N: 5 named cases is not a backtest. The headline P&L numbers are dominated by which 1–2 cases got picked, not by edge.
  • No transaction costs: no slippage, no borrow fees on shorts, no bid-ask. Real implementation would erode the +3pp marginal edge.
  • Synthetic ≠ real user behavior: the four-tier prior is a guess. Real users herd, follow correlated information, and panic — none of which the prior captures.
  • Reputation training is leak-y: leave-one-out per case is not real out-of-sample; in production reputation comes from prior trades, not concurrent ones.
  • Adversarial assumption is benign: independent-actor model. Coordinated attacks would require additional defences not tested.
The Monte Carlo validates architectural plumbing — does the reputation function correctly down-weight noise, does the population layer converge in K, does the synthetic-to-real transition protocol work mechanically. It does not validate that ROBO will produce alpha when real users arrive. That requires live deployment with paying users.
